# SKYHOOK

로우폴리 3인칭 케이블 스윙 타임어택. 시작 화면 오른쪽 카드에는 선택된 맵 하나만 표시되어(맵이 늘어도 카드 크기 고정) ‹ › 또는 ← →로 넘긴다. "전체 맵 보기"(M)를 누르면 모든 맵이 약도·난이도·길이·내 기록·전체 1위와 함께 스크롤되는 격자로 열리고, 이름 검색과 난이도 필터로 좁혀 칸을 누르면 선택, "출발"을 누르면 바로 시작한다. 격자는 방향키·Home/End로 이동, Enter 선택, Esc 닫기. 전체 1위 기록은 화면에 보이는 칸만 불러온다. 결과 화면의 "다른 맵 고르기"로 곧장 시작 화면으로 돌아간다.

맵은 난이도 순으로 놓인다. 각 맵의 `seed`가 풍경 배치를 고정하므로 순서(번호)를 바꿔도 건물·나무 위치는 그대로다.

캐릭터는 청록색 재킷, 얼굴이 드러나는 주황색 헬멧, 카고 바지와 크림색 부츠를 착용한 오리지널 도시 러너. 등에는 소형 화물 가방을 메고 허리의 기계식 릴에서 스윙 케이블이 연결된다.

## 실행

```sh
npm install
npm run dev -- --port 5174
```

랭킹 연결 정보(`ssalmuk_ranking` URL과 publishable 키)는 `src/ranking-config.js`에 들어 있어 별도 설정 없이 바로 연결된다. `npm run build`로 만든 `dist`는 정적 파일이라 Cloudflare Pages 등 어떤 호스팅에 올려도 된다(빌드 명령 `npm run build`, 출력 폴더 `dist`). 다른 Supabase 프로젝트를 쓰려면 빌드 환경 변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`로 덮어쓴다. 랭킹에 연결할 수 없어도 게임과 개인 기록은 그대로 동작한다.

자체 사이트(`npm run build`)에서는 광고 차단기가 켜져 있으면 시작 화면에서 안내 창이 뜨고 판이 시작되지 않는다(`src/adblock.js`: 미끼 요소 + 광고 스크립트 요청 두 가지로 판정, "다시 확인"으로 재검사). CrazyGames 빌드는 차단기가 켜져 있어도 플레이할 수 있어야 하므로(포털 규정) 이 검사와 광고 도메인 문자열이 빌드에서 빠진다.

결과 화면의 "기록 공유"는 맵과 기록을 담은 링크(`?map=<id>`)를 공유한다. 모바일에서는 공유 시트, 그 외에는 클립보드 복사. 링크로 들어오면 그 맵이 선택된 상태로 열린다. 포털 빌드는 바깥 링크가 금지라 버튼이 숨겨진다.

`npm test`로 보정 없이 훅 조종만으로 모든 맵을 완주할 수 있는지, 훅 없이 W만 누르면 코스를 따라 휘지 않고 직진하는지, 실제 맵 모델 충돌(출발·복귀 지점이 비어 있는지, 중앙에서 바깥으로 날아갈 때 처음 부딪히는 곳이 그려진 물체 표면인지, 실제 모델로 완주 가능한지), 곡선 트랙 투영, 추락 복귀, 체크포인트 순서, 타이머, 기록 데이터, Supabase 랭킹 SQL(실제 마이그레이션을 PGlite로 실행) 검증.

## 전체 랭킹 (Supabase `ssalmuk_ranking`)

여러 게임이 함께 쓰는 공용 랭킹 프로젝트 `ssalmuk_ranking`에 저장한다. 이 게임은 `skyhook`, 맵 7개는 각각 보드(`sunset`, `meadow`, `harbor`, `aurora`, `canyon`, `garden`, `jungle`)로 등록되어 있고, 아래 마이그레이션이 모두 적용되어 있다.

- `supabase/migrations/20260915000000_ranking_core.sql`: 공용 코어. 모든 게임이 공유.
- `supabase/migrations/20260915000100_skyhook_boards.sql`: SKYHOOK 게임·맵 등록.
- `supabase/migrations/20260915000200_skyhook_jungle_board.sql`: 몬순 정글 보드 추가.
- `supabase/migrations/20260915000300_skyhook_board_names.sql`, `20260915000400_skyhook_board_names_v2.sql`: 맵 이름 변경(현재: 메리골드 애비뉴·랜턴 하버·러스트 캐니언·전나무 설원·뭉게구름 정원·몬순 정글). 보드 id와 기존 기록은 그대로.
- `supabase/migrations/20260915000500_skyhook_meadow_board.sql`: 헤이스택 레인 보드 추가.

URL과 publishable 키는 브라우저에 공개되도록 만든 값이라 저장소(`src/ranking-config.js`)에 둔다. 접근은 RLS와 RPC 두 개로만 제한된다. `service_role`/secret 키는 절대 코드나 환경 변수에 넣지 않는다.

공용 코어 구성:
- `games`(게임), `boards`(게임별 맵·코스·모드. `higher_is_better`로 낮은 값/높은 값 우선, `min_value`~`max_value` 허용 범위, 선택적 페널티 규칙), `players`(익명 ID·최근 닉네임), `scores`(모든 제출 기록, 게임별 추가 정보는 `meta` JSON), `submit_log`(IP 해시 기반 요청 제한용, 10분 뒤 삭제).
- 모든 테이블은 RLS가 켜져 있고 정책이 없어 브라우저에서 직접 읽기·쓰기가 불가능하다. Supabase 보안 점검에 "RLS 정책 없음", "anon이 SECURITY DEFINER 함수 실행 가능" 안내가 뜨는데, 공개 RPC 두 개로만 접근하게 한 의도된 설계다.
- `get_leaderboard(p_game_id, p_board_id, p_limit, p_player_id)`: 보드별 플레이어 최고 기록 순위(동률이면 먼저 달성한 사람이 위)와 내 순위.
- `submit_score(p_game_id, p_board_id, p_player_id, p_name, p_value, p_meta)`: 검증 후 저장하고 개인 최고 갱신 여부와 현재 순위를 돌려준다. 플레이어당 분당 6회, IP당 분당 20회(전체 게임 합산)로 제한.

SKYHOOK 값은 완주 시간(밀리초, 낮을수록 좋음)이고 `meta.falls`(복귀 횟수)가 필수다. 추락 1회당 최소 시간이 3초씩 늘어난다. 맵을 추가하거나 트랙 길이·최고 속도를 바꾸면 `skyhook_boards` 마이그레이션의 `min_value`도 바꿔 다시 적용해야 한다. 값이 `src/maps.js`와 어긋나면 `npm test`가 실패한다.

### 다른 게임을 같은 랭킹에 추가하기

코어는 다시 만들 필요 없이 게임과 보드만 등록한다. 예: 생존 시간이 길수록 좋은 게임.

```sql
insert into public.games (id, name) values ('redline', 'REDLINE');
insert into public.boards (game_id, id, name, higher_is_better, min_value, max_value)
values ('redline', 'city', '시티', true, 0, 7200000);
```

게임 코드에서는 같은 URL·publishable 키로 `supabase.rpc('submit_score', { p_game_id: 'redline', p_board_id: 'city', ... })`와 `get_leaderboard`를 호출하면 된다. 보드 id는 게임마다 따로라 다른 게임과 이름이 겹쳐도 된다.
## 조작

- A: 왼쪽 연결점에 훅, D: 오른쪽 연결점에 훅. A+D 동시 입력은 양쪽 훅. 누른 키를 떼면 해당 케이블만 해제.
- W 전진, S 후진(내가 실제로 날아가는 방향 기준). 방향은 훅의 당김으로만 바뀌고, 두 훅을 놓으면 관성으로 직진한다. 코스를 따라 방향을 틀어주는 보정은 없다(카메라와 캐릭터도 코스가 아닌 실제 진행 방향을 따른다).
- 충돌은 보이지 않는 선이 아니라 맵에 실제로 그려진 물체(건물, 크레인, 절벽, 바위 아치, 나무, 가로등, 섬과 기둥, 출발대 등)의 면과 캐릭터 몸(반경 0.6 m)이 닿을 때만 일어난다. 옆에 아무것도 없으면 어디로 날아도 부딪히지 않는다. 부딪히면 게이트를 놓쳤을 때처럼 마지막 체크포인트로 돌아가며 3초가 추가된다. 실제 물체가 6 m 안에 들어오면 그 방향에 "충돌 주의"가 뜨고, 2.5 m 안에서는 빨갛게 깜빡인다.
- 판정하지 않는 것: 게이트 링과 연결점 표시(통과용 표시), 로프, 파티클, 반투명 폭포·물 반사, 움직이는 차·배·대관람차·새·하늘 고래·열기구. 바닥은 지금처럼 추락으로 처리한다.
- 훅은 내 진행 방향 기준 앞쪽·왼쪽/오른쪽의 연결점에 걸린다. 곡선에서는 가만히 있으면 코스 밖으로 날아가므로, 돌고 싶은 쪽 훅으로 직접 당겨 방향을 틀어야 한다. 연결점은 건물·바위·나무 등에 붙어 있어 한쪽 훅만 잡고 끝까지 흔들리면 그 물체에 부딪힐 수 있다.
- R 처음부터 다시, Escape 일시정지. 다른 창으로 전환하면 자동 일시정지.
- 모바일: 왼쪽 훅, 오른쪽 훅, W/S 버튼. 여러 손가락 동시 입력 지원.
- 게이트를 순서대로 통과하면 완주. 추락하거나 물체에 부딪히거나 게이트를 놓치면 마지막 체크포인트로 돌아가며 3초 추가.

## 기록과 랭킹

- **전체 랭킹(맵별):** 완주 후 이름을 입력하고 "랭킹 등록"을 누르면 서버에 저장된다. 한 사람당 그 맵의 최고 기록 하나로 순위를 매기고, 이름을 바꾸면 가장 최근 이름으로 표시된다. 결과 화면에 "전체 N위 / M명", 시작 화면 맵 카드에 전체 1위 기록·내 순위, HUD에 1위 기록이 보인다. "랭킹 보기"에서 맵을 바꿔가며 전체 랭킹 / 내 기록 탭을 볼 수 있다.
- **플레이어 식별:** 로그인 없이 브라우저마다 익명 ID(localStorage)를 만든다. 브라우저 데이터를 지우거나 다른 기기에서 하면 새 플레이어로 집계된다.
- **내 기록:** 기존처럼 같은 브라우저에 맵별 빠른 기록 10개를 저장하며, 랭킹에 연결할 수 없어도 저장된다(메리골드 애비뉴는 기존 키를 그대로 사용해 이전 기록 유지).
- **부정 기록 방지(기본 수준):** DB 함수가 등록되지 않은 맵, 코스를 최고 속도로 달려도 불가능한 시간(추락 1회당 +3초 반영), 1시간 초과 기록, 복귀 횟수가 빠진 기록을 거부하고 플레이어당 분당 6회·IP당 분당 20회로 등록을 제한한다. 기록 시간은 브라우저가 보고하므로 개발자 도구로 조작한 "그럴듯한" 시간까지 막지는 못한다. 확실히 막으려면 입력 기록을 서버(Supabase Edge Function 등)에서 물리 엔진으로 재생해 검증하는 방식이 필요하다.

## 구조

- `src/maps.js`: 맵 정의(중심선 제어점, 고저차, 게이트, 연결점 배치, 중력·최고 속도·바람). Three.js 없이 테스트에서 import.
- `src/physics.js`: 제어점을 Catmull-Rom 곡선으로 만들고 2 m 간격으로 재샘플링한 트랙 좌표계. 진자 제약·게이트·복귀를 "트랙 진행 거리 / 좌우 오프셋 / 지면 높이" 기준으로 계산.
- `src/worlds.js`: 테마별 3D 월드 생성(하늘·안개·조명·파티클 팔레트 포함). 정적 지오메트리는 재질·구역별로 병합해 드로우콜 절감.
- `src/collider.js`: 화면에 그려진 고정 물체의 삼각형을 격자로 색인해 캐릭터 몸과의 접촉·가장 가까운 물체를 계산.
- `src/main.js`: 맵 전환, 카메라, HUD, 입력, 랭킹 화면.
- `src/ranking-config.js`: 공용 랭킹 프로젝트 URL·publishable 키.
- `src/leaderboard.js`: Supabase RPC 클라이언트(익명 플레이어 ID, 캐시, 오프라인·미설정 처리). supabase-js는 처음 필요할 때 따로 불러온다.
- `supabase/migrations/`: 공용 랭킹 코어(테이블·RLS·RPC)와 SKYHOOK 보드 등록.

Three.js 0.184.0 / Vite 7.3.6. 외부 모델이나 텍스처 없이 게임 내 3D 지오메트리로 제작. 케이블 운동은 고정 120 Hz 타임스텝, 중력, 진자 제약, 점진적 릴 수축과 해제 시 접선 속도 보존을 사용.

```sh
npm run build:app   # dist-app/ (app.html이 index.html이 되고 경로는 상대 경로라 Capacitor에 그대로 넣는다)
```

- 조작은 훅 두 개뿐이다. 화면 왼쪽 절반을 누르고 있으면 왼쪽 훅, 오른쪽 절반은 오른쪽 훅(동시에 누르면 양쪽). PC에서는 A/D 또는 ←/→. W/S는 없고 속도는 스윙으로만 얻는다.
- 판마다 무작위 코스. 5 km마다 구간(DISTRICT)의 테마가 바뀌며 웹판 7개 테마를 메리골드 애비뉴 → 헤이스택 레인 → 랜턴 하버 → 전나무 설원 → 러스트 캐니언 → 뭉게구름 정원 → 몬순 정글 순서로 돈다.
- 테마는 경계 앞뒤 250 m씩(500 m)에 걸쳐 섞인다. 땅의 모양과 색이 한 테마에서 다음 테마로 서서히 변하고(뭉게구름 정원 쪽은 구름 아래로 가라앉음), 앞 테마의 건물·나무는 점점 드물어지며 다음 테마의 것은 경계 전부터 드문드문 나타난다. 연결점을 받치는 구조물도 두 테마가 나눠 맡고, 캐니언 절벽과 설원 능선은 경계 쪽에서 낮아진다. 하늘·안개·조명도 같은 구간에서 바뀐다.
- 난이도는 테마가 바뀔 때마다 한 단계씩 오르고(8번째 구간, 35 km부터 최고), 한 구간 안에서는 같다. 어려워지는 것은 **코스가 꼬불꼬불해지는 것**이다(장애물은 없다). 코스 모양은 테마와 상관없이 난이도로만 정한다: 긴 직선과 완만한 곡선에서 시작해 직선이 짧아지고 커브가 급해지며(반지름 1400–2600 m → 110–140 m) 좌우로 연달아 꺾이는 지그재그가 된다. 1 km당 꺾이는 각도 합은 대략 15° → 25° → 35° → 60° → 90° → 145° → 240° → 345°.
- 같은 단계에서 코스 폭(52 → 38 m), 연결점 간격(46 → 54 m, 좌우 엇갈림), 오르내림 경사도 조금씩 함께 바뀐다. 바람은 없다.
- 추락하거나 물체에 부딪히면 판이 끝나고 거리(m)가 기록된다. 최고 거리는 기기에 저장(`skyhook.app.best`). 이어하기·보석·랭킹은 다음 단계.
- 물리(중력·최고 속도)는 모든 구간이 같다. 충돌 규칙은 웹판과 같다(그려진 물체만 판정). 항구 구간은 수면이라 평평하다.

구조:
- `src/app/track.js`: 무한 트랙 생성(Three.js 없음). 난이도 단계(`difficulty`), 단계별 굽이(`bendStyle`), 구간·조각 정보. 방향이 시작 방향에서 55° 넘게 틀어지지 않아 코스가 되돌아와 겹치지 않는다. 오르막은 짧게 끊는다. 연결점 줄도 여기서 정한다. 같은 시드는 생성 순서와 상관없이 같은 코스.
- `src/app/scenery.js`: 625 m 조각 하나의 풍경(구간 하나 = 조각 8개). 웹판 테마를 코스 중심선 기준으로 다시 배치하고, 코스에서 떨어진 물체는 다른 코스 부분에 닿지 않는지 확인한 뒤 놓는다. 조각마다 충돌 색인을 따로 만든다.
- `src/app/main.js`: 조각 불러오기·지우기(한 프레임에 한 단계씩), 테마 경계의 환경 섞기, 터치 입력, HUD, 결과 화면.

`npm test`의 `tests/endless.test.js`가 시드 재현성, 테마 경계마다 난이도가 오르고 구간 안에서는 같은지, 경계에서 두 테마가 섞이는지(땅이 끊기지 않고 서로의 풍경이 건너편에 나오는지, 경계를 가로질러 날 수 있는지), 단계가 오를수록 코스가 더 꺾이는지, 곡률·되돌아옴·오르막 제한, 항구 평탄함, 연결점 간격, 사망 처리와 바람 없음, W 없이 훅만으로 모든 난이도 단계 통과(물리만 / 모든 테마의 가장 꼬불꼬불한 단계와 모든 경계를 실제 풍경 충돌 포함), 모든 테마·단계에서 비행 통로가 비어 있는지 검증한다.

## CrazyGames 빌드

같은 코드에서 포털용 빌드를 따로 만든다. 자체 사이트 빌드(`npm run build` → `dist/`)는 그대로다.

```sh
npm run build:crazygames       # Basic Launch 제출용 dist-crazygames/ (잠금 없음)
npm run build:crazygames:full  # Full Launch 제출용 dist-crazygames/ (07 맵 잠금)
npm run dev:crazygames         # 로컬에서 SDK 테스트 모드(데모 광고·배너)로 확인 (:full 붙이면 잠금 버전)
```

- 영어 페이지 하나(`en/index.html` 기반)에 CrazyGames SDK v3 스크립트를 넣고, 검색·공유용 태그·아이콘·언어 전환 링크는 뺀다. 경로는 모두 상대 경로.
- Adsterra 코드는 빌드에서 아예 제외된다(`src/ads-config.js`의 `OWN_SITE`). 배너는 SDK 배너로 시작 화면·결과 화면에만 뜨고 플레이 중에는 없다.
- 새 판을 시작할 때(재시작, 한 번 더) SDK midgame 광고를 요청한다. 광고 중에는 소리를 끄고 입력을 막으며, 빈도는 SDK가 3분 간격으로 제한한다. 첫 판은 광고 없이 바로 시작한다.
- 맵 잠금은 Full Launch용 빌드(`npm run build:crazygames:full`)에만 있다. 07 몬순 정글이 잠기고, 보상형 광고 하나를 끝까지 보거나(광고 실패 시 열리지 않음) 광고 없이 나머지 맵 6개를 모두 완주하면(`skyhook.cleared.<id>`) 계정에 영구히 열린다(`skyhook.unlocked.jungle`). 해금 창에 완주 진행도가 나오고, "광고 보고 열기"와 "다른 맵 고르기" 버튼은 같은 모양이다.
- Basic Launch에서는 CrazyGames가 광고를 꺼두므로 기본 포털 빌드(`npm run build:crazygames`)는 잠금 없이 모든 맵이 열려 있다. 광고 호출은 그대로 두며, 광고가 없으면 광고 없이 진행한다. 자체 사이트 빌드에도 잠금이 없다.
- 게임을 열면 곧바로 첫 판이 시작된다(Full Launch 요구사항 "Land directly in gameplay"). 메뉴는 일시정지에서 갈 수 있다.
- `gameplayStart/Stop`, `loadingStart/Stop`, 개인 최고 기록 시 `happytime`을 보낸다. 포털의 음소거 설정이 게임 소리 버튼보다 우선한다.
- 기록·선택한 맵·닉네임은 SDK data 모듈에 저장되어 CrazyGames 계정을 따라간다. 로그인한 플레이어는 CrazyGames 이름이 랭킹 이름 기본값이 된다.
- 폰트(Noto Sans KR·Barlow Condensed의 라틴 글자)는 빌드에 포함되어 Google Fonts를 부르지 않는다.
- 전체 랭킹(Supabase)은 그대로 요청한다. 포털 정책상 막히거나 거절되면 SDK 랭킹으로 바꾸거나 뺀다.
